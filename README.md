# LorenzAtractor_R
This is a interactive visualization of the Lorenz's atractor, here you can choose two values of $\rho$ and compare the orbits for the system for each value 

## How use it?
You just need download [app.R](app.R) and run it from [R Studio](https://rstudio--education-github-io.translate.goog/hopr/starting.html?_x_tr_sl=en&_x_tr_tl=es&_x_tr_hl=es&_x_tr_pto=tc)
